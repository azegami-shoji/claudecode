# 🎲 サイコロ日本一周

サイコロを振って日本全国の有名駅をめぐり、物件を買って資産1位を目指すすごろくゲームです。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要）。

- 1〜4人（人間 / CPU を自由に設定）、プレイ年数は 1・3・5・10 年
- サイコロの目の数だけ進めるマスがハイライトされるので、止まるマスを選ぶ
- **駅**: 物件を購入できる。毎年3月の決算で「価格 × 収益率」の収益が入る
- **独占**: 1駅の物件をすべて買うと、その駅の収益が2倍
- **青マス**: お金がもらえる / **赤マス**: お金を失う（冬は被害1.5倍） / **黄マス**: サイコロが増えるカード（急行・特急・新幹線）
- **🚩目的地**: 全国100駅からランダムに決定。一番乗りで賞金。到着すると次の目的地が決まる
- 所持金がマイナスになると、安い物件から半額で自動売却
- 最終年の決算後、総資産（所持金＋物件価格）が一番多い人の勝ち

地図はドラッグで移動、ホイール / ＋－ボタンで拡大縮小、駅をクリックすると物件一覧が見られます。

## ファイル構成

- `index.html` / `style.css` — 画面
- `js/data.js` — 駅（100駅、実際の緯度経度）・物件・路線データ
- `js/coast.js` — 日本列島の海岸線（Natural Earth 1:10m をもとに投影・簡略化）
- `js/game.js` — ゲームロジック・描画・CPU思考

## 🚗 サイコロ日本一周ドライブ（`drive/`）

電車ではなく**クルマで高速道路を走る**バージョンです。`drive/index.html` をブラウザで開くと遊べます。

- 目的地は全国の **SA・PA・有名な道の駅 52か所**（海老名SA、浜松SA、淡路SA、道の駅 阿蘇 など）
- マス目は東名・名神・東北道などの実在の高速道路。拡大すると道路名が見えます
- 北海道・四国・九州へは、フェリー（点線）や橋（アクアライン・明石海峡大橋・瀬戸大橋など、青い道）で渡ります
- 駅の「物件」は、SA・道の駅の「お店」に置き換え（ご当地グルメ・温泉・特産品）
- **ガソリン**：1マスで1目盛減り（満タン30）、SA・道の駅で給油（1目盛15万円）。0になるとJAF救援で1,500万円
- **通行料**：高速1マス8万円・橋20万円・フェリー40万円（ETCカード使用ターンは半額）
- カードは ETC（2個）・ターボ（3個）・ニトロ（4個）、赤マスは渋滞・パンク・スピード違反など

### ファイル構成

- `drive/index.html` / `drive/drive.css` — 画面（`../style.css` と `../js/coast.js` を共用）
- `drive/js/data.js` — 52スポット（実際の緯度経度）・お店・高速道路データ
- `drive/js/game.js` — ゲームロジック・描画・CPU思考
